# Java Journey

A self-paced learning path for Java developers — from absolute beginner to middle-level engineer — built as a set of interactive checklists.

## What's inside

Three interlinked resources, each in its own HTML file:

- **[Projects](projects.html)** — 120 project ideas across 12 tiers, from "Hello, World!" to a production-shaped capstone. Filter by track, search concepts, tick them off as you build.
- **[Algorithms](algorithms.html)** — 177 interview-style problems across 16 topics, tagged Easy/Medium/Hard with the approach for each. Filter by topic or difficulty.
- **[Stack Atlas](stack.html)** — A reference for every language feature, library, tool, and pattern the projects touch. Linked back to the projects that exercise them.

The **home page** (`index.html`) shows combined progress across the two trackable checklists and links to all three.

## Why it exists

Most "learn Java" resources are either too shallow (a list of tutorials) or too scattered (bookmarks, half-finished courses). This one is opinionated:

- **Sequential.** Follow the tiers in order — each project builds on the ones before it.
- **Depth over breadth.** After tier 6, pick one vertical and go deep.
- **Concept-first.** The goal isn't to finish a project, it's to understand *why* you chose a pattern, a library, a trade-off.
- **Self-contained.** No accounts, no server, no tracking. Your progress is stored in your browser only.

## Running locally

Just open `index.html` in a browser — everything is static. Or serve the folder with any static file server.

## Project links

Each project card links to a repository (currently pointing to a placeholder). Replace `REPO_URL` in `projects.html` and `algorithms.html` with your own when the projects exist.
