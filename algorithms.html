Not Problems, But Required

The habits that actually move the needle in an interview. Treat them as ongoing practice.

  • Explain while you code. Narrate your thinking — interviewers weight communication as heavily as correctness.
  • Write clean code under pressure. Sensible names, small methods, no magic numbers.
  • Test with edge cases. Empty input, single element, duplicates, overflow, negative numbers.
  • Analyze before optimizing. State the brute-force cost first, then improve.
  • Re-solve without looking. If you can't reproduce a solution a week later, you haven't learned it.
  • Do timed mocks. 45 minutes, one whiteboard, no autocomplete.
  • Learn one language deeply. Collections, streams, and quirks of Java — not just syntax.
