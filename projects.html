A Java Developer's Project Library

120 projects, ordered from "hello world" to a deployable, observable, production-shaped system. Every project introduces new concepts while reinforcing the ones before it.

Tick a box when you've built it and understood it. Progress is saved in this browser. Use the search and filters above to focus.

How to use this list

  • Sequential learning. Follow the tiers in order — concepts build on each other.
  • Tracks. Full-stack = web/API/Spring depth. Distributed = messaging, resilience, cloud. Architecture = design, DDD, capstone. Foundation tiers (1–6) appear in every track.
  • Search & filter. Press / to focus the search box. Click any tier card below to filter to that tier. Combine chips, tracks and search — they all stack.
  • Don't do all 120. After Tier 6, pick one vertical to go deep. Depth beats a shallow sweep.
  • Focus on concepts. The goal isn't finishing the project — it's understanding why you chose a pattern, a library, a trade-off.
  • Export. Hit ⬇ PDF — filters are ignored during print, so you get the full list.

Tier 1

The Absolute Basics

Console applications only. No external libraries — just core Java, the compiler, and the terminal.

Not Projects, But Required

These aren't checkbox items — they're the habits that move you from "knows Java" to "middle-level engineer". Treat them as ongoing.

  • Contribute to open source. One merged PR in a real project teaches more about code review than ten tutorials.
  • Review other people's code. And accept reviews on yours without ego.
  • Read production code. Follow the design of a well-regarded OSS codebase — Spring, Kafka clients, OkHttp.
  • Practice system design out loud. Design "a URL shortener" or "a news feed" with trade-offs in 45 minutes.
  • Write ADRs for every capstone decision. Context, options, choice, consequences. Senior interviews probe exactly this.
  • Debug a production-shaped incident on purpose. Kill the DB, fill the disk, write a post-mortem.
  • Work on soft skills. Estimation, breaking down ambiguous tickets, asking clarifying questions, written English.
